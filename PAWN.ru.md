# Menu Core для Pawn-плагинов

[English](PAWN.md) | [Русский](PAWN.ru.md)

Menu Core отдаёт 29 нативов оригинального `menu_core.amxx` (`mc_register_action`, `mc_show_menu`, `mc_add_menu_item` и остальные) с сигнатурами из его `menu_core.inc`, так что собранные `.amxx`-плагины работают без изменений. Он заменяет `menu_core.amxx`: старый плагин закомментируйте в `plugins.ini`.

Колбэки задаются именем публичной функции, и Menu Core вызывает их в том плагине, который их зарегистрировал.

`include/menu_core.inc` из пакета отличается от оригинала только записью, а не тем, что передаёт собранный плагин:

| Оригинал | Этот пакет |
| --- | --- |
| `#define MP_LOCKED 0` … `MP_FILTER 7` | `enum MenuProperty { MP_LOCKED = 0, … }` |
| `property` в трёх нативах свойств | `MenuProperty:property` |
| `mc_get_menu_property_string(menuIdx, property, value[], len)` | `…, out[], len)` |
| `mc_add_list_text(Array:aItems, …)` | `mc_add_list_text(aItems, …)` |
| — | `mc_get_menu_text(id, out[], len)`: что сейчас показывает меню игрока |

Плагин, собранный с новым инклудом, получит предупреждение о теге на голое число там, где ждут `MenuProperty:`, и на `Array:`, переданный в `mc_add_list_text`.

### Чем отличается от оригинального `menu_core.amxx`

- Нет ограничений Pawn: названия, заголовки и подстановки любой длины, меню хранит все пункты, путь назад любой длины, меню длиннее 500 байт отправляется целиком.
- `mc_get_menu_property_string(idx, MP_SECTION)` работает; оригинал сравнивал `MP_SECTION` (5) с 4.
- Фильтр условия применяется везде, где спрашивают условие, как и написано в `menu_core.inc`; оригинал применял его только к ограничениям.
- `message` ограничения показывается рядом с посеревшим пунктом, если у пункта нет своего сообщения; оригинал его хранил, но не показывал.
- Когда меню закрывается, потому что поверх открылось другое, колбэки закрытия получают его имя; оригинал передавал `""`.
- Заблокированное меню делает серыми пункты любого меню; оригинал — только строки списков.
- `mc_show_menu` для секции, которую никто не регистрировал, читает её из файла.
- `isCritical` у `mc_register_action` принимается и ничего не делает, как в оригинале.
